# Visual Similarity Search

Find visually similar images using CLIP embeddings and approximate nearest neighbor search.

## Problem

Given an image, find other images in a collection that look similar or share semantic content — the core idea behind visual search features like Pinterest's "similar pins."

## Status

Early WIP — setting up embedding pipeline and search index.

## Tech Stack

Python, CLIP, FAISS, Streamlit
